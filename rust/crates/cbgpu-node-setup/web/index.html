GPU SERVER SETUP

학교 GPU를 연결하세요

학교 관리 화면에서 받은 등록 파일로 이 컴퓨터를 연결합니다. 비밀번호를 입력하거나 드라이버를 자동으로 바꾸지 않습니다.

실행 환경을 확인하고 있습니다.

1. 서버 먼저 준비하기

Ubuntu x86_64와 NVIDIA 드라이버가 필요합니다. Jupyter를 사용할 때는 Docker와 NVIDIA Container Toolkit도 준비하세요.

Jupyter를 사용할 경우 아래 버튼으로 고정 이미지를 준비할 수 있습니다. 다운로드는 수 GB이며 Docker 저장 공간을 사용합니다. 준비를 마친 후 연결 파일을 발급하세요.

2. 개인 등록 파일 선택

아직 선택하지 않았습니다.

정책 파일이 필요합니다.

작업 공간은 임시 저장소입니다. 작업 종료 전 결과를 백업하세요. 연결만으로 자원 이용 권한이 생기지는 않습니다.

등록·정책이 포함된 연결 파일 하나도 사용할 수 있습니다. 실행 옵션은 직접 선택해야 합니다. Linux에서는 개인 폴더에 보관하고 Windows에서는 도우미 메모리에만 보관합니다. 토큰을 주소·명령행·로그에 넣지 않습니다.

3. 검사 후 설치

버튼을 누르면 읽기 전용 환경 검사를 실행합니다. 드라이버나 설정은 바꾸지 않습니다.

기존 identity 또는 사용자 서비스가 있으면 자동으로 교체하지 않습니다. 로그아웃·재부팅 이후에도 유지하려면 사용자 lingering 설정을 별도로 확인하세요.

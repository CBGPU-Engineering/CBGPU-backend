# Welcome to CBGPU Engineering

This guide is for contributors who have received a joining confirmation from the
team. Submitting an application does not automatically approve membership.

## 1. Join Slack

Open the [CBGPU Engineering invitation](https://join.slack.com/t/cbgpuengineering/shared_invite/zt-4fk9n8tkx-F1TSN9wCapb5FmH4ISGpdg).
Sign in or create a Slack account, confirm the workspace, and set a recognizable
display name. If the invitation expires, contact `info@cbgpu.com` for a new link.

## 2. Post your introduction and GitHub ID

Post this introduction in the default conversation channel, or the introduction
channel your team contact specifies. **Your GitHub ID is required so the team can
invite the correct account.** Create a GitHub account first if needed.

```text
Hi, I'm [name] and I'm joining CBGPU!
Role / interests: [frontend / backend / mobile / infrastructure / design / product]
GitHub ID: [username]
GitHub profile: https://github.com/[username]
I'd like to work on: [one sentence]
```

Do not post passwords, authentication codes, tokens, or private credentials.

## 3. Open Jira

Open [CBGPU Jira](https://cbgpu.atlassian.net/?continue=https%3A%2F%2Fcbgpu.atlassian.net%2Fwelcome%2Fsoftware%3FprojectId%3D10000&atlOrigin=eyJpIjoiZTNmMTVjMDAwNjNlNGRiODkwZTNjNmRhNDQ4MTMzMjkiLCJwIjoiamlyYS1zb2Z0d2FyZSJ9)
and sign in with an Atlassian account. Using the same email as Slack makes it
easier for the team to find you. If the project is not visible, ask your team
contact in Slack to invite that email. A project invitation may be required;
the link itself does not grant access.

## 4. Accept your GitHub invitation

After your GitHub ID is posted, the team can invite you to the appropriate
organization/repositories. Check GitHub notifications and email and accept the
invitation. Posting an ID in Slack does not grant permissions automatically.

Organization: https://github.com/CBGPU-Engineering

## 5. Agree on a first task

Share your availability and interests with your team contact. Find your first
task in Jira, update its status when starting, and ask for help in Slack when
blocked. Read the relevant repository's README and CONTRIBUTING instructions.
Use a branch and Pull Request for code changes. Confirm production deployments
and operational data changes with the team before acting.

The browser version at `/onboarding` includes a copyable introduction and a
five-step checklist. Checkbox state is not stored or shared.

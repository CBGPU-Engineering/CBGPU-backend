합류 안내를 받은 새 팀원을 위한 시작 가이드예요.

지원서 제출만으로 합류가 확정되는 것은 아니에요. 담당자에게 합류 안내를 받았다면 아래 순서대로 진행해주세요. Slack 초대 링크는 만료되거나 운영자가 변경할 수 있어요. 접속되지 않으면 info@cbgpu.com으로 알려주세요.

01. Slack 워크스페이스에 참여해요

아래 초대 링크를 열고 사용할 이메일로 가입하거나 로그인하세요. 워크스페이스 이름이 CBGPU Engineering인지 확인하고, 팀원이 알아볼 수 있도록 표시 이름을 설정해주세요.

Slack 참여하기 ↗

02. Jira에 가입하고 접속해요

아래 링크를 열고 Atlassian 계정을 만들거나 기존 계정으로 로그인하세요. Jira에 가입한 이메일을 확인해두고, 다음 단계에서 자기소개와 함께 Slack에 올려주세요. 프로젝트가 아직 보이지 않아도 가입 이메일을 공유하면 담당자가 초대할 수 있어요. 접근 권한 오류가 나오면 화면의 메시지도 함께 알려주세요.

CBGPU Jira 열기 ↗

03. 자기소개와 계정 정보를 Slack에 올려요

Slack 참여와 Jira 가입을 마친 뒤, 기본으로 참여된 대화 채널에 GitHub ID와 Jira 가입 이메일을 포함해 아래 양식으로 메시지를 올려주세요. 채널이 여러 개라면 담당자가 안내한 자기소개 채널을 이용해주세요.

안녕하세요! CBGPU에 합류한 [이름]입니다.
담당/관심 분야: [프론트엔드 / 백엔드 / Android / iOS / 플랫폼·인프라 / 디자인 / 기획·운영]
GitHub ID: [아이디]
Jira 가입 이메일: [Atlassian 계정 이메일]
함께 해보고 싶은 일: [한 줄 소개]

GitHub ID와 Jira 가입 이메일은 꼭 Slack에 남겨주세요. GitHub ID는 저장소 초대에, Jira 가입 이메일은 프로젝트 초대에 사용해요. Slack 이메일과 달라도 실제 Jira에 가입한 이메일을 적어주세요. GitHub 계정이 없다면 먼저 github.com에서 계정을 만든 뒤 공유해주세요. 비밀번호, 인증 코드, API 키는 올리지 마세요.

04. GitHub 초대를 확인해요

담당자가 Slack에 올린 ID를 확인하고 GitHub 조직·저장소에 초대해요. GitHub 알림과 이메일을 확인해 초대를 수락해주세요. Slack에 ID를 올리는 것만으로 저장소 권한이 자동 부여되지는 않아요.

05. 첫 작업을 함께 정해요

담당자와 활동 가능 시간과 관심 분야를 나눈 뒤 Jira에서 첫 작업을 확인하세요. 작업을 시작할 때 상태를 갱신하고, 막힌 부분은 Slack에 공유해주세요. 코드 작업은 해당 저장소의 README와 CONTRIBUTING을 읽고 브랜치와 Pull Request로 진행해요.

새 팀원에게 운영 서버 비밀번호나 개인 인증 정보를 공유하지 않아요. 권한이 필요하면 담당자에게 요청하고, 운영 데이터 변경·배포는 먼저 팀과 확인해주세요.
